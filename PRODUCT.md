## 2. Target Audience & Visitor Intent

### Primary Audience
1. **Tech Recruiters & Talent Scouts**:

2. **Engineering Leads & Senior Developers**:

   - *Key Needs*: Evidence of deep frontend skill (custom canvas particle systems, WebGL floating lines, clean responsive layouts).
3. **Clients & Founders**:
   - *Goal*: Determine whether Natanael can build high-end, premium web applications that elevate their brand.

---

## 3. Core Principles & Experience Contract

1. **Artifact Leads First**:
   - The user is inside the creative work. The interface recedes cleanly while projects, code, and interactive visual elements command attention.
2. **Anti-AI-Slop Standard**:
   - Zero generic AI clichés: no arbitrary rainbow/gold gradients, no bouncy rubber-band animations, no clashing multi-color sections.
   - Everything decelerates with natural physics (`cubic-bezier(0.16, 1, 0.3, 1)`).
3. **Cohesive Visual Authority**:
   - Unified Dark Tech palette (`#0c0c1d` void background with locked `#8b5cf6` / `#a78bfa` Electric Violet accent).
4. **Frictionless Action**:
   - Instant navigation via floating sidebar, one-click email copy or contact modal, clear live demo buttons.
5. **Mobile Integrity**:
   - No cut-off canvas elements, no horizontal overflow, and fully scaled particle density on mobile screens (viewport height stability via `--vh` calculation).
